# Media Player

Настільний мультимедійний плеєр для Windows, створений мовою Python із використанням PySide6 та VLC. Застосунок відтворює локальні аудіо- й відеофайли, а також медіа за прямими HTTP/HTTPS-посиланнями.

## Можливості

- відкривання локальних медіафайлів і прямих URL;
- плейлист із ручним та автоматичним переходом між файлами;
- додавання медіа через діалог або Drag and Drop;
- Play/Pause кнопкою, клавішею `Space` або натисканням на відео;
- повторний запуск завершеного відео натисканням на область кадру;
- перемотування, смуга прогресу та відображення часу;
- керування гучністю і Mute з відновленням попереднього рівня;
- швидкість відтворення `0.5x`, `1x`, `1.5x` і `2x`;
- повноекранний режим та автоматичне приховування панелі;
- адаптивна панель керування і плаваючий плейлист;
- підтримка гарячих клавіш.

## Вимоги

- Windows 10 або новіша версія;
- 64-бітний [VLC media player](https://www.videolan.org/vlc/);
- Python 3.10 або новіша версія — лише для запуску з вихідного коду.

Розрядність Python або `MediaPlayer.exe` повинна відповідати розрядності VLC.

## Запуск готового застосунку

1. Встановіть VLC media player.
2. Запустіть файл `dist/MediaPlayer.exe`.

Для запису діагностичних повідомлень запустіть застосунок із параметром `--debug`:

```powershell
.\dist\MediaPlayer.exe --debug
```

Логи зберігаються у каталозі `logs` поруч із поточною робочою папкою.

## Запуск із вихідного коду

Відкрийте PowerShell у каталозі проєкту та виконайте:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Якщо PowerShell не дозволяє активувати середовище, запускайте його Python напряму:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

У Visual Studio Code потрібно відкрити каталог проєкту, вибрати інтерпретатор `.venv\Scripts\python.exe` і натиснути `F5`.

## Керування

| Клавіша | Дія |
| --- | --- |
| `Space` | Play/Pause |
| `Left` / `Right` | перемотування на 10 секунд |
| `Up` / `Down` | зміна гучності |
| `M` | Mute/Unmute |
| `F` | повноекранний режим |
| `Ctrl+Left` / `Ctrl+Right` | попередній або наступний файл |
| `Esc` | вихід із повноекранного режиму |
